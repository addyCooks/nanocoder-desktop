Type to jump in the model, mode and browser profile dropdowns. Typing the start of an option's name now moves to the next option that starts with it, several letters typed together narrow the match, and a closed dropdown opens on the match without changing the value until you press Enter. In a list too long to show at once, the highlighted option now scrolls into view, with the arrow keys as well.
